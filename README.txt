Abo6 Gamer Portfolio
====================
المشروع عبارة عن موقع بورتفوليو عربي متجاوب للجيمر محمود (Abo6).

الملفات:
- index.html: هيكل الموقع + تحميل React و ReactDOM من CDN.
- style.css: التصميم والألوان والحركات والاستجابة للموبايل.
- script.js: تفاعلات JavaScript وReact والقائمة النشطة.

طريقة التشغيل:
1) فك ضغط الملف.
2) افتح index.html في المتصفح. يحتاج الإنترنت لتحميل خط Cairo ومكتبات React من CDN.
3) غيّر روابط يوتيوب وتيك توك داخل index.html إلى روابط حساباتك الحقيقية.

ملاحظة:
الموقع يستخدم رسومات CSS وإيموجي كعناصر بصرية أصلية بدل صور ألعاب رسمية، ويمكن لاحقًا استبدالها بصورك أو صور مصرح باستخدامها.
